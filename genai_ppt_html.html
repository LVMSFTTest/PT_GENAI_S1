Slide 6Ethical Considerations & Biases

Key risks:

  • Hallucination — model generates plausible but factually wrong content
  • Training data bias — models reflect stereotypes present in web-scale data
  • Copyright — models trained on copyrighted text/images
  • Misinformation — synthetic media (deepfakes, fake news) at scale
  • Privacy — memorisation of personal data from training sets

Transformer Architecture
Self-attention, encoder-decoder, multi-head attention, FFN hidden layers
Slide 7Why Transformers?

Before transformers — the problem with RNNs/LSTMs:

  • Processed tokens sequentially → slow, poor long-range memory
  • Vanishing gradient problem — early tokens "forgotten" in long sequences
  • Could not be parallelised during training
2017 breakthrough: "Attention Is All You Need" (Vaswani et al.) — replaced recurrence with self-attention. Entire sequence processed in parallel. Scales extremely well with compute.
Slide 8Transformer Architecture — Overview
🔵 Encoder — understanding
  • Sees entire input at once (bidirectional)
  • Used in: BERT, RoBERTa
  • Good for: classification, Q&A
🟢 Decoder — generating
  • Generates one token at a time
  • Used in: GPT-3, LLaMA
  • Good for: text generation
🔵🟢 Encoder-Decoder — both
T5, BART — understands input, generates output. Best for translation, summarisation.
Slide 9Step 1 — Tokenisation & Embedding

Tokenisation (BPE / WordPiece):

  • "unhappiness" → ["un", "happiness"]
  • GPT-3 vocabulary: ~50,257 tokens

Embedding: Each token ID → dense vector (e.g., 768 floats). Similar words cluster together.

"king" − "man" + "woman" ≈ "queen" — embeddings encode meaning arithmetically

Positional Encoding:

PE(pos, 2i) = sin(pos / 10000^(2i/d))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
Without this, "cat sat" = "sat cat" to the model
Slide 10Self-Attention Mechanism

Three learned projections per token:

Query (Q) — what am I looking for?Key (K) — what do I advertise?Value (V) — what info do I share?
Attention(Q, K, V) = softmax( Q·Kᵀ / √d_k ) · V

Steps:

  • Compute Q·Kᵀ dot products → raw relevance scores
  • Divide by √d_k → prevent vanishing gradients
  • Apply softmax → probabilities summing to 1
  • Weighted sum of Values → new token representation
Example: "The animal didn't cross the street because it was too tired" — "it" attends strongly to "animal", weakly to "street"
Slide 11Multi-Head Attention
  • Run H attention heads in parallel, each with different W_Q, W_K, W_V matrices
  • Each head learns a different relationship type
HeadWhat it learns
Head 1Coreference ("it" → "animal")
Head 2Syntax (verb → its object)
Head 3Semantics (adjective → noun it modifies)
BERT-base
12 heads × 64 dims = 768 total
GPT-3
96 heads × 128 dims = 12,288 total
Slide 12Masked (Causal) Attention
  • Used in the decoder during autoregressive generation
  • Triangular mask sets future positions to −∞ before softmax → weight → 0
  • Token at position t can only attend to positions 1…t
Why it matters: Without the mask, the model "cheats" by peeking at future tokens during training. At inference, those tokens don't exist yet.
Attention mask:
       The   cat   sat
The  [  ✓     ✗     ✗  ]
cat  [  ✓     ✓     ✗  ]
sat  [  ✓     ✓     ✓  ]
Slide 13Feed-Forward Network — The Hidden Layers
  • Applied to each token independently after attention
  • 2-layer MLP with GELU/ReLU activation
FFN(x) = max(0, x·W₁ + b₁) · W₂ + b₂
ComponentBERT-base dimsParameters
Input / Output768—
Hidden layer (W₁)3,072 (4× model dim)768 × 3072 = 2.4M
Output layer (W₂)7683072 × 768 = 2.4M
Key insight: Research (Geva et al., 2021) shows FFN layers act as key-value memories — they store factual associations like "Paris is the capital of France."
Slide 14Add & Norm — Residual Connections
Residual (Add)
output = sublayer(x) + x

Creates a gradient highway — prevents vanishing gradients in deep networks. Even if a layer learns nothing, the original signal passes through.

Layer Norm
Normalises vector to mean ≈ 0, std ≈ 1.

Stabilises training — prevents activation explosion or collapse.

Early layers capture syntax. Middle layers capture semantics. Late layers capture task-specific patterns.

Pre-training & Fine-tuning
The two-phase training paradigm, objectives, LoRA, and RLHF
Slide 16The Two-Phase Training Paradigm
Phase 1 — Pre-training
  • Massive unlabelled corpus (web, books, code)
  • Objective: next-token or masked-token prediction
  • Very expensive: GPT-3 cost ~$4.6M
  • Result: powerful general-purpose model
Phase 2 — Fine-tuning
  • Start from pre-trained weights
  • Small task-specific labelled dataset
  • Much cheaper: hours on one GPU
  • Result: task-specialist model
Analogy: Pre-training = 12 years of school. Fine-tuning = 3-month job training.

Slide 18Fine-tuning Strategies

Full fine-tuning: Update all weights. Best performance, most expensive.

LoRA (Low-Rank Adaptation):

  • Freeze base model weights
  • Add small trainable rank-decomposition matrices: ΔW = A·B where rank r ≪ d
  • Reduces trainable parameters by ~10,000×
  • Used in most production fine-tuning today

Prompt / Prefix tuning: Add trainable "soft prompt" tokens. Base model completely frozen.

Full fine-tuneLoRAPrompt tuningRLHF
Slide 19RLHF — Aligning Models with Human Preferences
Used in GPT-4, Claude, Gemini to make models helpful, harmless, and honest

Step 1 — Supervised Fine-Tuning (SFT): Fine-tune base model on high-quality human-written demonstrations.

Step 2 — Reward Model Training: Show human raters pairs of outputs, ask which is better. Train a reward model to predict human preference scores.

Step 3 — PPO Optimisation: Use reward model as a "judge." Fine-tune LLM using reinforcement learning. Reward: human-preferred responses. Penalty: diverging too far from SFT model (KL divergence).

Slide 21GPT-3 — The Few-Shot Giant
  • 175 billion parameters, 96 transformer layers
  • Trained on 570GB of text (Common Crawl, WebText, Books, Wikipedia)
  • Key innovation: in-context learning — no gradient updates needed at inference
Zero-shot
Just a task description. No examples.
Few-shot
1–10 examples in the prompt. Model generalises.
Limitations: Knowledge cutoff, hallucination, no real-time grounding, prompt-sensitive
Slide 22T5 — Every Task as Text-to-Text
  • "Text-To-Text Transfer Transformer" (Google, 2020)
  • Encoder-decoder architecture
  • Reformulates ALL NLP tasks as text-to-text:
Translation:     "translate English to French: The cat sat" → "Le chat s'est assis"
Summarisation:   "summarize: [article]" → "[summary]"
Q&A:             "question: Capital of France? context: ..." → "Paris"
Pre-trained with span corruption (not next-token prediction). Best for structured, well-defined generation tasks.

  • Strong on: long-form content, creative writing, structured data generation
  • Accessible via AI21 Studio API
Less widely benchmarked than GPT-3/4 but competitive on generation quality for specific domains

Slide 28Text Generation — GPT-2 Example
from transformers import pipeline

generator = pipeline("text-generation", model="gpt2")

result = generator(
    "Once upon a time in a land of transformers,",
    max_new_tokens=80,
    num_return_sequences=2,
    temperature=0.8,    # creativity: 0=deterministic, 1=random
    top_p=0.92,         # nucleus sampling
    do_sample=True
)

for r in result:
    print(r['generated_text'])
    print("---")

Strengths & Limitations
What LLMs do well, known failure modes, and mitigation strategies
Slide 31What LLMs Do Well
  • Few-shot learning: Solve new tasks from just 2–5 examples in the prompt
  • Cross-domain transfer: Strong on tasks never explicitly trained for
  • Instruction following: Understand complex, multi-part natural language instructions
  • Code generation: GPT-4 passes FAANG-style coding interviews
  • Long-form coherence: Maintain consistent narrative over thousands of tokens
  • Reasoning chains: CoT prompting enables step-by-step problem solving
  • Multilingual: A single model handles 50+ languages
Slide 32Known Limitations
LimitationDescriptionExample
HallucinationConfidently generates false facts"Einstein won Nobel Prize for relativity" ✗

Slide 33Strategies to Mitigate Limitations

Retrieval Augmented Generation (RAG):

  • Connect LLM to a vector database of up-to-date documents. Model retrieves relevant context before generating → reduces hallucination

Tool use / Function calling:

  • LLM calls APIs, runs code, queries databases. Grounds responses in real data.

Chain-of-Thought (CoT) prompting:

  • "Let's think step by step" → forces intermediate reasoning. Dramatically improves maths and logic tasks.

Domain fine-tuning:

  • Train on specialised medical/legal/financial text → reduces hallucination in domain-specific tasks.
Slide 34Key Takeaways
  • Generative AI learns to create, not just classify
  • Transformers replaced RNNs with parallelisable self-attention
  • Encoder = understanding; Decoder = generation; both = seq2seq
  • Multi-head attention learns multiple relationship types simultaneously
  • Masked attention ensures honest autoregressive generation
  • FFN hidden layers are where factual knowledge is stored
  • Pre-training + fine-tuning is the standard recipe — Hugging Face makes it accessible
